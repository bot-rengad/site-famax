# FMX Optimisation

## Installation rapide

### Windows
Double-clique sur `Installer.bat` — tout se configure automatiquement.

### Mac/Linux
```bash
npm install --legacy-peer-deps
cp .env.example .env
npm run db:generate
npm run db:push
npm run db:seed
npm run dev
```

## Lancer le site
```bash
npm run dev
```
Ouvrir http://localhost:3000
